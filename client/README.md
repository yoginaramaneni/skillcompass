# SkillCompass Client

React + Vite + TypeScript frontend for SkillCompass.

## Key Setup

- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **HTTP**: Axios (`src/lib/axios.ts`)

## Vercel Deployment

Deploy directly by specifying root directory as `client`, build command `npm run build`, and output directory `dist`.
